# Nordic Trip 2027

2027 年挪威与冰岛旅行计划（2027-02-08 至 2027-02-21）。

## 网站

网站首页：`index.html`。通过 GitHub Pages（Deploy from a branch / main / root）发布。

预计访问地址：https://errrror.github.io/nordic-trip-2027/

## 说明

包含逐日行程、日出日落、路线与地图、摄影点、签证材料、行李清单和预算。

所有航班、住宿、价格均为规划候选项，以最终预订和官方信息为准。Evenes（EVE）机场不允许在航站楼内过夜，2 月 14 日的夜间安排仍需解决。

请勿在公开仓库提交护照号、个人联系方式、真实订单编号等敏感信息。
